# End-to-end demonstration

The included recordings and fresh outputs generated by the pipeline are located under:
- `04_DEMO/recording/bootcamp_test_meeting.wav` → `04_DEMO/outputs/bootcamp_test_meeting/`
- `04_DEMO/recording/effective_meetings_15min.mp3` → `04_DEMO/outputs/effective_meetings_15min/`
- `04_DEMO/recording/last_meals_30min.mp3` → `04_DEMO/outputs/last_meals_30min/`

## Running the Demonstration

1. From the repository root, activate the virtual environment:
   ```bash
   source .venv/bin/activate
   ```
2. Ensure dependencies are installed and `.env` has a valid `GROQ_API_KEY`:
   ```bash
   python -m pip install -r 03_DEPENDENCIES/requirements.txt
   ```
3. Start the interactive Gradio application:
   ```bash
   python run.py
   ```
4. Open the local Gradio interface (typically `http://127.0.0.1:7860`).
5. In the upload panel, choose or drop `04_DEMO/recording/bootcamp_test_meeting.wav`.
6. (Optional) Enter terminology in the glossary box (e.g. `PGvector, PostgreSQL 16, PyTorch`).
7. Click **Start Processing** and monitor the 10-stage progress stepper.
8. Once complete, inspect the results across the three interface tabs:
   - **Raw Transcript**: Local Faster-Whisper transcript with segment timestamps.
   - **Refined Transcript**: Domain-corrected transcript preserving timestamp anchors.
   - **Final Output**: Complete Markdown meeting record including Summary, Minutes, Decisions, Discussed Not Decided, Action Items (with task, owner, deadline, status, and evidence), Discussion Points, and Open Questions.
9. Click **Download Results Package** to save the generated ZIP archive containing all Markdown and JSON deliverables.
